# Note sur le quai numéro quatre

Note de service de l'an 1398, devenue obsolète.

Le quai numéro quatre du port de Port-Ysel est réservé aux barques de pêche de l'Écume Bleue. Le Conseil des Quais en décidera l'affectation définitive à la prochaine séance. Cette note sera retirée des archives dès que le quai sera attribué.
