# Charte du Conseil des Quais

Version révisée de l'an 1413, qui remplace la charte de l'an 1290.

## Composition

Le Conseil des Quais de Port-Ysel compte neuf sièges. Aux sept corporations d'origine s'ajoutent un siège pour les îles extérieures (Keld et Brumeval) et un siège pour Sarnoux.

## Mandat

Les conseillers sont élus pour un mandat de six ans. Un conseiller peut être réélu deux fois. Le maître de port est élu directement par les conseillers pour trois ans et préside les séances.

## Quorum et décisions

Le Conseil délibère valablement lorsque six conseillers sont présents. Les décisions importantes exigent la majorité des deux tiers. En cas d'égalité, le vote est reporté à la séance suivante.

## Séances

Le Conseil se réunit le quinze de chaque mois dans la Halle des Cordages. Toutes les séances sont publiques, y compris celles qui concernent la quarantaine.
